# 复现验证记录

此文件记录本提交版本的实际验证范围。具体数值证据会在验证完成后写入同目录 JSON 文件。

验证环境：Windows 64 位，Python 3.13.9，`requirements.lock` 锁定全部 35 个直接和传递依赖。随机种子 2026。原始数据和预处理数据由 SHA-256 固定。允许浮点末位差异，比较容差为 `rtol=1e-9, atol=1e-8`。

验证分为全新虚拟环境安装、随包输入与模型验证、完整特征重训、图像全量重提和重新训练、换目录 Git 克隆后的运行、GUI 初始化与单图推理。各项最终结果见下方完成记录；不把未执行的 GitHub 云端工作流写成已经通过。

本仓库不声称在任意 Python、任意依赖版本或任意操作系统上产生逐位相同的结果。图表受系统字体影响，模型文件受序列化实现影响；验收对象是数据内容、样本划分、视觉特征、分类预测与连续性状预测以及相应评估数值。
